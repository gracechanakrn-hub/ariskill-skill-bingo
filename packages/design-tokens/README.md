# @ariskill/design-tokens (PROVISIONAL)

Provisional design tokens for AriSkill Skill Bingo. The AriSkill design system was not available for this run (OD-12), so **every token here is provisional** and carries a `null` entry in `tokens.json#verified.map` until the brand owner maps it. No brand logos or colours are claimed. The sans stack is the self-hosted Plus Jakarta Sans (OFL-1.1, `packages/vendor/plus-jakarta-sans/`, loaded via its `fonts.css`) with the system UI font as fallback. **1.2.0** adds the sticker language (docs/art/sticker-art-direction.md, D-25): `--sticker-navy`, `--sticker-space`, `--sticker-aurora-teal`, `--sticker-aurora-lime`, `--sticker-lilac`, `--sticker-violet-deep`, `--sticker-mint`, `--sticker-cyan`, `--sticker-peach`, `--sticker-gold`, `--sticker-rose`, `--sticker-badge`, `--sticker-badge-ink`, `--sticker-outline`, `--sticker-shadow` and `--font-display` (`"Fredoka", "Plus Jakarta Sans", sans-serif`; Fredoka is OFL-1.1, vendored at `packages/vendor/fredoka/`, weight 500-700, loaded via its `fonts.css` next to the Plus Jakarta Sans link). Sticker colours are constant across the dark and light themes (they are art, not semantic UI colours) and are never the only signal. Contrast pairs carried by the tests: pill ink on pill fill 10.1:1, navy on lime 15+:1 (lime labels always use navy text, never white), body text >= 4.5:1 on every tile surface including the sticker sky.

## Files

- `tokens.json` - source of truth: `themes.dark` (`:root`), `themes.light` (`[data-theme="light"]`, flat admin surfaces only), `themes.venue` (`.theme-venue`, public/stage type scale), the provisional-to-verified map and the colour rules.
- `tokens.css` - generated by `node packages/design-tokens/build.js`; do not hand-edit. `node build.js --check` fails if it is stale.
- `test/tokens.test.js` - presence of every token in JSON and CSS, WCAG contrast (4.5:1 text, 3:1 UI) for dark and light, colour-vision-deficiency separability of Core vs Critical vs Optional (Machado 2009 simulation), venue minimums, 8 px rhythm, 44 px touch target, self-hosted font present with no remote font URLs.

## Use

```html
<link rel="stylesheet" href="/packages/design-tokens/tokens.css">
<body>                       <!-- dark by default (employee mobile, public, stage) -->
<body data-theme="light">    <!-- admin portal -->
<body class="theme-venue">   <!-- public screen / stage dashboard at 1920x1080 -->
```

Rules carried with the tokens (see `docs/art/art-direction.md`):

- Core = `--color-core` (amber) + filled diamond + label; Critical = `--color-critical` (cyan) + filled circle + label; Optional = `--color-optional` + outlined circle + label. Colour is never the only signal.
- Reduced motion: `@media (prefers-reduced-motion: reduce)` collapses all `--duration-*` to a single 120 ms fade and `--ease-emphasized` to the standard curve. Durations are never 0.
- `--ease-emphasized` never overshoots (motion agent request).

## Commands

```
node packages/design-tokens/build.js          # regenerate tokens.css
node packages/design-tokens/build.js --check  # verify no drift
node --test packages/design-tokens/test
```
