## API (base `/api/v1`; full contract in contracts/api-contract.yaml — normative)
- `GET /time` -> { serverTime, epochMs }
- Public: `GET /events/{eventId}/snapshot`, `GET /events/{eventId}/stream` (SSE), `GET /events/{eventId}/join-info`
- Participant (Bearer session): `POST /events/{eventId}/session` { joinToken, employeeRef, displayName, consentPublicName } -> { sessionToken, participantId, eventId, expiresAt }; `GET /me`; `GET /me/stream`; `GET /taxonomy`; `POST /me/profile` { platformId, roleId }; `GET /skills/discovery?mode=recommended|popular|search&q=&limit=`; `PUT /me/board/selections` { skillIds, boardVersion } (Idempotency-Key); `POST /me/board/finalize` { boardVersion } (Idempotency-Key); `GET /me/insight`; `POST /me/soul/float` { soulId, floatToken } (Idempotency-Key) -> { accepted, replay, entrance }
- Admin (Bearer admin): `GET /admin/events/{id}/snapshot`, `/stream`, `/insights`, `/audit?roundId=&limit=`, `/join-link`; `POST /admin/events/{id}/rounds` { title, lockAt, resultWindowSeconds } (Idempotency-Key); `POST /admin/rounds/{roundId}/commands` { command, expectedVersion, params } (Idempotency-Key) with commands round.update | round.registration.open | round.reschedule | round.lock | round.start | round.start_now {confirmed:true} | round.draw.next {} | round.cancel {reason} | round.close
- Stage (Bearer stage or admin): `GET /stage/events/{id}/snapshot`, `/stream`
- Every 2xx JSON carries correlationId + serverTime (+ resultingVersion on mutations). Errors: `{ error: { code, message, exceptionId, details }, correlationId, serverTime }`; STALE_VERSION (409) details = { currentVersion, snapshot }. error.message already contains the E-copy for coded exceptions; look up `exception(id)` in /packages/contracts/index.js for trigger/recovery.
- Default event id: `evt_demo`. Board saves need boardVersion (0 before first board). Rate limits: commands 10/s, session 5/min per IP, discovery 20/s.
- SSE frames: `id: <sequence>\nevent: <type>\ndata: <envelope JSON>`; resume via `?since=` or `Last-Event-ID`; replay window 500; `system.snapshot_required` or a gap -> refetch the audience snapshot (has `sequence`, `serverTime`). Event types and payloads: contracts/realtime-events.json. Participant `draw.accepted.myMatchedPositions` = cumulative matched positions after the draw. `board.deferred.reason` may be incomplete|late|cancelled. `round.updated` may carry `startOverdue: true`.

## Shared UI kit (`/packages/ui/*.js`, `/packages/ui/base.css`) — see packages/ui/README.md for full API
- api-client.js: `createApiClient({ baseUrl:'/api/v1', getToken, clockSync })` -> get/post/put/del; ApiError { code, message, exceptionId, details, status, isStaleVersion, staleSnapshot, isAuth, isNetwork }; auto Idempotency-Key; retries only network/502-504.
- clock-sync.js: `createClockSync({ fetchTime: () => api.get('/time') })` -> sync(), now(), isSynced; `formatCountdown(targetIso, nowMs)` -> 'mm:ss'; `remainingMs`.
- sse-client.js: `createSseClient({ url, getToken, onEvent(envelope, meta{ connectionEpoch, replay, gap }), onGap, onStatus, since })` -> start/stop/acknowledgeSnapshot(seq); status idle|connecting|open|reconnecting|closed. Pattern: snapshot -> applySnapshot -> start({since}); on reconnect (epoch>1) or onGap: refetch snapshot, applySnapshot, acknowledgeSnapshot. Celebrate only when meta.replay === false plus your own id-keyed dedup.
- store.js: createStore, applySnapshot (always wins), applyEvent(store, envelope, reducer), select.
- dom.js: `h(tag, attrs, ...children)`, mount, announce(text,{politeness}), focusTrap(modal), setPending(button, bool), escapeHtml, qs/qsa. Never use innerHTML with server strings (XSS, T13).
- format.js: plural, formatInt, formatTime, relativeSeconds, pseudonymLabel, ordinal, padTwo.
- qr.js: `qrToSvg(text, { size, margin, dark, light, ariaLabel })` -> SVG string (render at >= 256 px); `renderQr(container, text, opts)`.
- telemetry.js: track(event, props) no-op sink.
- base.css classes: .container .stack .cluster .grid .card .app-header .app-main .sticky-bottom; .btn(--primary/--danger/--ghost/--block/--lg) .is-pending; .chip(--core/--critical/--optional) .chip__remove .chip-list; .option[aria-pressed]; .field .input .select .checkbox .search; .tabs .tab .tabpanel; .pill(--live/--open/--reconnecting/...); .toast-region .toast; .banner; .modal-backdrop .modal; .countdown(--display); .bingo-grid(--stage)(.is-locked) > .bingo-cell(--core/--critical)(.is-matched/.is-line) .bingo-cell__name .bingo-cell__kind; .progress; .stat(--display); .draw-card(--core/--critical); .draw-list; .qr; .skip-link; .visually-hidden; .tabular; .display.

WCAG 2.2 AA: keyboard operable, visible focus, 44 px targets, live-region announcements for accepted draws/results without focus theft, reduced-motion and mute respected, zoom/reflow to 320 px on mobile.
